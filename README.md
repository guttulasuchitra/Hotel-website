# 🏨 Hotel ALBATROSS

A clean and modern hotel website designed using HTML & CSS.

## 🚀 Overview

Hotel ALBATROSS is a static web project showcasing a premium hotel experience in Andhra Pradesh. It consists of Home, About, and Contact pages designed to deliver essential information in a visually appealing layout with smooth navigation.

## 🌟 Features

- 🧭 Simple and clean navigation bar
- ⭐ Guest testimonials section
- 🖼 Hotel showcase visuals
- 🎨 Custom UI styling using CSS
- 📱 Ready for responsiveness with a separate mobile CSS file

🌐 View Website Here: 

  https://albatross-hotel.netlify.app/



## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Figma** for image assets

This project helped me:

- Improve frontend development skills
- Apply UI/UX design concepts
